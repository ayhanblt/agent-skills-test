# Merchant provider fixture v1

POST /api/provider/webhook with JSON {"id":"evt-1","type":"payment.paid","paymentId":"pay-2"}.
X-Provider-Time is a canonical decimal Unix second. X-Provider-Signature is the lowercase hexadecimal HMAC-SHA256 of UTF-8 timestamp + ASCII dot + exact HTTP body bytes. Signing key comes only from MO_PROVIDER_SECRET. Allow an inclusive ±300 seconds against the injected TimeProvider. Unknown/missing signature, malformed timestamp, or age outside the window: 401. Compare fixed length MAC bytes in constant time. Invalid payload or empty IDs: 400. JSON bodies are bounded at 16 KiB (413 if exceeded). An unknown payment returns 404, with no event recorded. Successfully processed event returns 200. Replay of exactly the same body for the same event ID still returns 200 after a newly valid signature; an ID reused with different raw bytes returns 409. Verify signature and freshness before replay lookup. Concurrent deliveries are equivalent to serial delivery. A committed event ID changes the payment exactly once. In local fault mode, X-Simulate-Fault: webhook-before-commit returns 503 after writes but before commit. The payment and event must both roll back. No real credentials or event payloads are logged.
