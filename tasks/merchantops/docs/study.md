# MerchantOps V2 calibration

The research title remains **Agent Skills gerçekten yardımcı mı?** The planned main sample is 72 runs. This version authorizes only 18 calibration pilots and separate technical smoke tests. V1 task code, transcript and telemetry remain separate. A changed benchmark cannot isolate whether general versus specialist skill content caused a difference (H6).

H1: installation does not ensure automatic selection. H2: procedural knowledge may improve functional success. H3: gains may differ across the two verified models. H4: gains can trade off with regression or rule compliance. H5: they can trade off with time, tokens and API-equivalent cost. H6: different knowledge types may help differently, and this cross-version contrast is exploratory.

References: [SkillsBench](https://arxiv.org/abs/2602.12670), [SWE-Skills-Bench](https://arxiv.org/abs/2603.15401), [Claude Code Skills](https://code.claude.com/docs/en/skills), and the pinned technology notes. Their datasets are not part of this study.
