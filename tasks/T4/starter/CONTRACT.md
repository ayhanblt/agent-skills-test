Export createCache(fetcher) and useResource(cache,key). fetcher(key,{signal}) returns a promise; hook returns {status,data,error,retry}. Empty key is idle. Cache shared across components: one in-flight request per key, stable snapshots, all subscribers notified. Unmounting one subscriber must not abort others. Last subscriber leaving aborts in-flight work; remount starts fresh after abandoned work (even if abort ignored). retry starts a new request and invalidates/aborts old work for that key. Old successes, failures and finally handlers cannot modify the new generation. Success persists in cache for remount without refetch; error is retryable explicitly. Different keys remain independent. StrictMode-safe. No global singleton, timers, new dependency or signature changes.

### Shared cache invalidation and refresh
Also expose cache.invalidate(key) for mutations that invalidate cached data. For a subscribed nonempty key it starts a new request immediately, superseding any in-flight request, and affects every subscriber for that key. For an unsubscribed key it marks the entry stale without starting a request; the first subscriber starts one refresh. Invalidating an empty key does nothing.

A refresh started by retry or invalidate retains the last successful data while status is loading; error is cleared. If that refresh fails, status is error, the error is exposed, and the last successful data remains available. A refresh success publishes the replacement data to all current subscribers. When the last subscriber leaves during a refresh, abort it and keep any last successful data marked stale. On remount, show it while starting a fresh request. Late responses from abandoned or superseded generations must have no effect, even while a new request is still running.
