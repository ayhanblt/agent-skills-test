Export createPayments(provider). It returns {pay(key, request)}. request={amount,currency}; provider.charge(key,request) returns a promise of a JSON receipt. Concurrent and later identical requests share one charge and an equal receipt. A reused key with different amount/currency rejects with code CONFLICT. Reject empty keys, non-positive/non-integer amounts and non-uppercase three-letter currency with code INVALID before any provider call. Unrelated keys progress independently. A rejected charge may be retried with the same key. Scope: one service instance, no restart guarantee.
