Export useSearch(query,search) React hook returning {status,data,error}. search(query,{signal}) returns a promise. Empty query => idle, data=null,error=null and no request. Nonempty query => loading with data/error null, then success with returned data or error with the thrown Error. Changing query or search invalidates prior completions (success AND failure); abort previous transport when invalidated or unmounted. Correctness must hold if abort is ignored and in StrictMode. Clear stale data/error when starting. Do not change the public signature or add dependencies.
