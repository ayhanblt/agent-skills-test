# T5 — tus Core and Creation

Add a resumable route at /api/uploads and /api/uploads/{id} using tus 1.0.0. Keep the existing document API. This route holds upload content until completion; it does not attach the resource to a dispute automatically.
OPTIONS /api/uploads returns 204, Tus-Version 1.0.0, Tus-Extension creation, Tus-Max-Size 1048576. Except OPTIONS, all tus responses carry Tus-Resumable: 1.0.0. Missing or unsupported request version returns 412 with Tus-Version. Require X-Operator alice or bob, 401 otherwise. A different owner sees 404 for HEAD/PATCH and content. 
POST with no body and integer Upload-Length from 0 through 1048576 creates a durable upload and returns 201, Location (relative is acceptable), and offset 0. Missing/malformed/negative length is 400, over limit 413. No deferred lengths or creation-with-upload. HEAD returns 200, Upload-Length, Upload-Offset, Cache-Control: no-store. PATCH requires application/offset+octet-stream, integer nonnegative Upload-Offset, and correct current offset, with 415, 400 and 409 respectively on mismatch. Do not advance offset on any failure. Reject bytes beyond remaining length with 413. Success returns 204 and the authoritative offset. Persist owner, bytes, length and offset across restarts and serialize writes to each upload. GET /api/uploads/{id}/content is a fixture endpoint that returns exact bytes of the completed upload, 409 if still incomplete.
