Export createTransfer(storage,{size,sha256}). storage adapter: read() returns Buffer of committed bytes (initially empty); commit(buffer) atomically durably replaces bytes and may throw; no direct filesystem/network. Return {offset(),write(offset,bytes,chunkSha256),finish()}; synchronous methods. Validate declared size is nonnegative integer and sha256 is 64 lowercase hex. write validates nonnegative integer offset, nonempty Buffer, matching SHA-256, no gap, no overflow. Invalid operations throw code INVALID and leave bytes unchanged. New chunk must start exactly at committed offset. A fully committed identical replay (also subrange) returns current offset; conflicting or partial overlap rejects INVALID. Return durable offset only after commit succeeds; propagate storage errors. Recreating the transfer resumes from storage.read(), rejecting persisted length > size. finish returns a defensive Buffer iff exact length and whole hash agree, otherwise throws INVALID. Never reset storage on failure.
